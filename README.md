# Ecclesia — لوحة تحكم إدارة الحضور والاجتماعات الكنسية
> **Church Attendance Management Admin Dashboard**

واجهة ويب إدارية حديثة ومتكاملة لإدارة الحضور والاجتماعات والفعاليات الكنسية، مبنية باستخدام **React 19** و**TypeScript** و**Tailwind CSS v4** و**Vite**، ومصممة وفق أرقى معايير الـ Dark Dashboard واللغة العربية الكاملة (RTL).

## 🚀 التقنيات المستخدمة (Core Stack)

- **الواجهة الأساسية:** React 19 + TypeScript (Strict Mode)
- **أداة البناء والتطوير:** Vite + `@vitejs/plugin-react`
- **التنسيق والأنماط:** Tailwind CSS v4 + متغيرات التصميم المخصصة (CSS Custom Properties)
- **الخطوط:** خط عربي أصيل متغير **Noto Sans Arabic**
- **التنقل والمسارات:** React Router DOM (v7)
- **إدارة البيانات والحالة:** `@tanstack/react-query`
- **الجداول التفاعلية:** `@tanstack/react-table`
- **الرسوم البيانية والإحصائيات:** `recharts`
- **النماذج والتحقق:** `react-hook-form` + `zod` + `@hookform/resolvers`
- **توليد رمز الاستجابة السريع:** `qrcode.react` (توليد SVG وCanvas عالي الدقة مع التنزيل والطباعة)
- **معالجة التواريخ:** `date-fns` مع التعريب الكامل `ar-EG` وتوقيت القاهرة
- **الإشعارات المنبثقة:** `sonner` المتوافقة مع اتجاه RTL
- **الاختبارات الآلية:** `vitest` + `@testing-library/react` + `@testing-library/jest-dom` + `jsdom`

## 🛠️ أوامر التشغيل والاختبار

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. تشغيل بيئة التطوير المحلية:
```bash
npm run dev
```
سيعمل الخادم المحلي فورًا عبر الرابط: `http://localhost:5173/`

### 3. تشغيل الاختبارات الآلية (Vitest):
```bash
npm test
```
تشمل 9 اختبارات تفحص قواعد العمل والتحويلات والمكونات.

### 4. بناء نسخة الإنتاج:
```bash
npm run build
```

## 📱 الصفحات المكتملة في النظام

1. **لوحة التحكم الرئيسية (`/dashboard`):**
   - تحية ترحيبية وفلتر زمني متقدم (اليوم، 7 أيام، 30 يومًا، هذا الشهر، فترة مخصصة).
   - 6 بطاقات مؤشرات حيوية متناسقة رقميًا مع الجداول والرسوم البيانية.
   - مخطط أعمدة بياني تفاعلي (Recharts) لمقارنة الحضور والغياب المؤكد.
   - أحدث جلسات الحضور مع أزرار الانتقال السريع للتفاصيل.
   - سجل النشاط الإداري للعمليات الأخيرة.

2. **إدارة الأعضاء (`/members`):**
   - جدول ذكي يدعم البحث بالاسم أو الهاتف، والتصفية حسب الحالة والمرحلة والنوع.
   - نافذة إضافة عضو جديد مع فحص صحة رقم الهاتف المصري `01[0125]\d{8}`.
   - نافذة تعديل بيانات العضو (مع إبقاء الهاتف للقراءة فقط كمعرف أمني).
   - نافذة الملف الكامل للعضو مع زر مراسلة واتساب المباشرة.
   - قبول طلبات التسجيل المعلقة بضغطة زر.
   - إيقاف الحساب أو إعادة تفعيله أو تعطيله (Soft Delete مع نافذة تأكيد).

3. **جلسات الحضور (`/attendance-days`):**
   - استعراض الجلسات المجدولة، المفتوحة، المغلقة، والمعتمدة.
   - إنشاء جلسة جديدة مع التحقق من أن وقت النهاية يأتي بعد البداية.
   - أزرار فتح وإغلاق التسجيل وتأكيد اعتماد الجلسة.

4. **تفاصيل الجلسة ورمز QR (`/attendance-days/:id`):**
   - **لوحة QR Code:** توليد رمز استجابة حقيقي عالي الدقة.
   - تنزيل الرمز بصيغة **PNG** أو **SVG**.
   - طباعة بطاقة الرمز الجاهزة للتعليق بالقاعة بضغطة زر.
   - تدوير وتجديد الرمز لمحاكاة منع مشاركة لقطات الشاشة.
   - تبويبا **الحاضرون** و**الغائبون** مع عدادات فورية وإمكانية تصدير CSV.
   - تسجيل الحضور اليدوي الاستثنائي للأعضاء غير المسجلين مع تدوين السبب.

5. **إدارة الفعاليات (`/events`):**
   - نمطا عرض: شبكي ببطاقات غنية، وجدولي.
   - تحديد حالة التوقيت تلقائيًا (قادمة، جارية الآن، منتهية).
   - ربط الفعالية بجلسة حضور تلقائية والانتقال بينهما بسلاسة.
   - تبديل حالة الفعالية بين منشورة ومسودة.

6. **التقارير والتحليلات (`/reports`):**
   - فلاتر تاريخ، مرحلة، وحالة جلسة.
   - ملخص أداء الفترة ونسب الحضور.
   - **نظام الافتقاد الرعوي:** كشف تلقائي للأعضاء ذوي نسب الغياب المرتفعة لمساعدة الخدام في المتابعة.
   - تصدير ملفات CSV مشفرة بـ `UTF-8 with BOM` لضمان فتح النصوص العربية في Microsoft Excel بدقة متناهية دون تشويه.

7. **الإعدادات والتواصل (`/settings`):**
   - بيانات الكنيسة الرسمية، ورقم الهاتف، والبريد الإلكتروني.
   - رابط التواصل المباشر مع مسؤول الشباب على واتساب.
   - روابط مجموعات واتساب المخصصة للذكور وللإناث، ورابط صفحة فيسبوك مع التحقق من صيغ الروابط.
   - إمكانية إعادة تعيين بيانات المعاينة (Demo Mode) لحالتها الأصلية بضغطة واحدة.

## 🔌 الجاهزية للربط المستقبلي مع ASP.NET Core Web API

صُممت طبقة الخدمات بالكامل لتطابق عقود الـ DTOs المعرفة في وثيقة التحليل الوظيفي:
- تم عزل المنطق داخل `services/` (مثل `membersService`, `attendanceDaysService`, `attendanceService`).
- يدعم التطبيق عنوان الخادم عبر المتغير البيئي:
  ```env
  VITE_API_BASE_URL=https://api.yourchurch.org/api/v1
  ```
- عند توفر الخادم، يكفي استبدال نداءات `mockStorage` بطلبات `fetch` أو `axios` القياسية دون تعديل أي من مكونات الواجهة الرسومية!
